1. OVERVIEW
========================================================================
MoDEV Technology is a high-performance technology startup specializing in:
  - Generative AI & Foundation Models (Claude 3.5, GPT-4o, Llama 3, DeepSeek)
  - Agentic AI & Autonomous Multi-Agent Workflows (LangGraph)
  - Retrieval-Augmented Generation (RAG) & Hybrid Graph Knowledge Bases
  - Model Context Protocol (MCP) Tool Integration
  - AegisShield Prompt Injection Defense & Zero-Trust Cybersecurity
  - Scalable Enterprise Backends (Java Spring Boot, Python FastAPI, Node.js)
  - Modern Responsive Web Applications (React 18, TypeScript, Tailwind CSS)

========================================================================
2. KEY SECTIONS & CAPABILITIES
========================================================================
- HERO SECTION: High-impact engineering messaging with live simulated 
  agent telemetry log terminal & interactive architecture switcher.
- TRUST STRIP: Capability ticker badges highlighting core technical domains.
- SERVICES & SOLUTIONS: 10 enterprise service cards with interactive detail 
  specifications and architecture proposal triggers.
- AI ARCHITECTURE FOCUS: Interactive pipeline topology (User -> Gateway -> 
  LLM -> Reasoning Agent -> RAG Memory -> MCP Tools -> Enterprise DB).
- AGENTIC AI SECTION: Multi-agent execution workflow visualizer with 
  interactive real-time goal decomposition simulation.
- TECHNOLOGY ECOSYSTEM: 7 categorized tech domains with filter pills and 
  featured competency indicators.
- SELECTED WORK (PORTFOLIO): Large project cards featuring live metrics, 
  tech tags, embedded video demo modals, and architectural case studies.
- ENGINEERING PROCESS: 6-phase pipeline (Discover, Architect, Engineer, 
  Validate, Deploy, Evolve) rendered as desktop & mobile timelines.
- SECURITY ENGINEERING: AegisShield prompt injection firewall code spec, 
  ephemeral tool execution sandboxing, and ZK audit trails.
- WHY US: Comparative matrix contrasting traditional agencies against 
  MoDEV Intelligent Engineering.
- ABOUT & LEADERSHIP: Executive story, mission principles, and core team.
- CONTACT SECTION: Interactive project inquiry form with multi-select 
  technology domain selector and simulated response handling.

========================================================================
3. TECH STACK & DEPENDENCIES
========================================================================
- Frontend Framework: React 18
- Language: TypeScript 5.7+
- Styling: Tailwind CSS 3.4+ & PostCSS
- Icons: Lucide React (vector icons)
- Animations: Framer Motion & CSS custom keyframes
- Build Tool: Vite 6.1+

========================================================================
4. QUICK START & DEVELOPMENT
========================================================================
To run the project locally on your machine:

1. Install Dependencies:
   npm install

2. Start Development Server:
   npm run dev

3. Build for Production:
   npm run build

4. Preview Production Build:
   npm run preview
